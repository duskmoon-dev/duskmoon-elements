# Carousel

Native scrolling, scroll-snapping content carousel using the public DuskMoon Core 1.19.9 CSS contract.

## Installation

```bash
npm install @duskmoon-dev/el-carousel
```

```javascript
import '@duskmoon-dev/el-carousel/register';
```

## Properties

| Property      | Type          | Default     | Description      |
| ------------- | ------------- | ----------- | ---------------- | ----------- | ------------------- |
| `orientation` | `'horizontal' | 'vertical'` | `'horizontal'`   | Scroll axis |
| `align`       | `'start'      | 'center'    | 'end'`           | `'start'`   | Item snap alignment |
| `color`       | `theme color` | `—`         | Foreground color |

## Composition and accessibility

Each direct child is a carousel item. The internal scroller is keyboard focusable and retains its native scrollbar.
