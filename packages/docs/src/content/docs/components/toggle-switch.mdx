# Toggle Switch

Toggle Switch wraps a native checkbox with `role="switch"`; the browser owns activation and checked state.

<ComponentDemo title="Notifications">
  <el-dm-toggle-switch name="notifications" value="enabled" color="primary" checked>
    Enable notifications
  </el-dm-toggle-switch>
</ComponentDemo>

Properties include `checked`, `disabled`, `required`, `name`, `value`, `size` (`xs`, `sm`, `md`, `lg`), `color`, and `ghost`.
