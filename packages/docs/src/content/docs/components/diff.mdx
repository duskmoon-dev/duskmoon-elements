# Diff

Before-and-after content comparison using the public DuskMoon Core 1.19.9 CSS contract.

## Installation

```bash
npm install @duskmoon-dev/el-diff
```

```javascript
import '@duskmoon-dev/el-diff/register';
```

## Properties

| Property   | Type          | Default    | Description                                      |
| ---------- | ------------- | ---------- | ------------------------------------------------ |
| `position` | `number`      | `50`       | Before layer reveal percentage, clamped to 0–100 |
| `ratio`    | `string`      | `'16 / 9'` | CSS aspect ratio                                 |
| `static`   | `boolean`     | `false`    | Show layers side by side                         |
| `color`    | `theme color` | `—`        | Foreground color                                 |

## Composition and accessibility

The `before`, `after`, `before-label`, and `after-label` slots map to the upstream composition. A separate range input can update `position`; the element does not create application state.
