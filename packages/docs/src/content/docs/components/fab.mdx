# FAB

FAB owns placement and uses native Popover state for its action list. Applications supply action semantics and handlers.

```bash
npm install @duskmoon-dev/el-fab
```

<ComponentDemo title="Contained speed dial">

    </el-dm-fab>
  </div>
</ComponentDemo>

`start`, `contained`, and `extended` select Core layout variants. `disabled` disables the native trigger. `show()` and `hide()` delegate to the native Popover.
