# Stat

Structured metric with title, value, description, figure, and actions using the public DuskMoon Core 1.19.9 CSS contract.

## Installation

```bash
npm install @duskmoon-dev/el-stat
```

```javascript
import '@duskmoon-dev/el-stat/register';
```

## Properties

| Property | Type          | Default | Description |
| -------- | ------------- | ------- | ----------- |
| `color`  | `theme color` | `—`     | Value color |

## Composition and accessibility

Available named slots are `title`, `value`, `description`, `figure`, and `actions`. Use meaningful HTML inside slots, such as terms and descriptions when the surrounding context is a description list.
