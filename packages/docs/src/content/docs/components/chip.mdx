# Chip

The Chip component displays compact tags, links, actions, filters, and removable selections.

## Installation

```bash
npm install @duskmoon-dev/el-chip
```

## Usage

```javascript
import '@duskmoon-dev/el-chip/register';
```

```html
<el-dm-chip>Tag</el-dm-chip>
```

## Properties and Attributes

| Property      | Attribute      | Type                                                                                    | Default         | Description                                              |
| ------------- | -------------- | --------------------------------------------------------------------------------------- | --------------- | -------------------------------------------------------- |
| `variant`     | `variant`      | `'filled' \| 'outlined' \| 'soft'`                                                      | `'filled'`      | Visual style                                             |
| `color`       | `color`        | `'primary' \| 'secondary' \| 'tertiary' \| 'success' \| 'warning' \| 'error' \| 'info'` | -               | Chip color                                               |
| `size`        | `size`         | `'sm' \| 'md' \| 'lg'`                                                                  | `'md'`          | Chip size                                                |
| `href`        | `href`         | `string`                                                                                | -               | Enables link mode and sets the link destination          |
| `target`      | `target`       | `string`                                                                                | -               | Link browsing context; used only with `href`             |
| `rel`         | `rel`          | `string`                                                                                | -               | Link relationship; used only with `href`                 |
| `clickable`   | `clickable`    | `boolean`                                                                               | `false`         | Enables action-button mode                               |
| `selectable`  | `selectable`   | `boolean`                                                                               | `false`         | Enables toggle-button mode                               |
| `deletable`   | `deletable`    | `boolean`                                                                               | `false`         | Shows a delete button                                    |
| `deleteLabel` | `delete-label` | `string`                                                                                | `'Remove chip'` | Accessible name for the delete button                    |
| `selected`    | `selected`     | `boolean`                                                                               | `false`         | Selected state; toggled automatically in selectable mode |
| `disabled`    | `disabled`     | `boolean`                                                                               | `false`         | Disables the active interaction mode                     |

```html
<!-- Display: a non-focusable span -->
<el-dm-chip>Release 1.8</el-dm-chip>

<!-- Link: a native anchor -->
<el-dm-chip href="/releases" target="_blank" rel="noopener">Releases</el-dm-chip>

<!-- Clickable: a native action button -->
<el-dm-chip clickable>Refresh</el-dm-chip>

<!-- Selectable: a native toggle button -->
<el-dm-chip selectable selected>TypeScript</el-dm-chip>

<!-- Deletable: a label with a native delete button -->
<el-dm-chip deletable delete-label="Remove TypeScript filter">TypeScript</el-dm-chip>
```

When multiple mode attributes are present, the mode precedence is `deletable` → `href` →
`selectable` → `clickable` → display. This prevents nested interactive controls. Prefer one mode
attribute per chip unless you intentionally rely on this precedence. The `target` and `rel`
properties apply only when `href` wins.

## Events

| Event       | Detail                  | Description                                      |
| ----------- | ----------------------- | ------------------------------------------------ |
| `dm-click`  | -                       | Fired when a link or clickable chip is activated |
| `dm-change` | `{ selected: boolean }` | Fired after a selectable chip toggles            |
| `dm-delete` | -                       | Fired when the delete button is activated        |
| `delete`    | -                       | Deprecated alias emitted with `dm-delete`        |

These custom events bubble, cross the shadow boundary, and are cancelable. Canceling `dm-click`
prevents link navigation. Native `click` events from the rendered anchor or button are also
available. Disabled chips do not emit action events.

### Event Handling

```javascript
const chip = document.querySelector('el-dm-chip');
const filterInput = document.querySelector('#filter-input');
chip.addEventListener('dm-delete', () => {
  chip.remove();
  filterInput?.focus();
});
```

The component emits the removal request but never removes itself. If the application removes the
focused chip, it must move focus to the next logical chip, the previous chip, or the owning input.

Use `dm-delete` for new integrations. The unprefixed `delete` event is retained only as a
deprecated compatibility alias.

## Accessibility

- Display chips render as plain, non-focusable spans.
- Link, clickable, and selectable modes use native anchors or buttons for built-in keyboard and
  focus behavior.
- Selectable chips expose `aria-pressed` and retain focus after their selected state changes.
- Deletable chips use a focusable native button. Customize its accessible name with
  `delete-label`; the visual delete icon is hidden from assistive technology.
- Disabled buttons use the native `disabled` state. Disabled links render as noninteractive spans
  with `aria-disabled="true"`, and disabled deletable chips disable their delete button.
